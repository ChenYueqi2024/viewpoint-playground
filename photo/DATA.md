# Motorcycle · stereo reference
Photos and reference data by Daniel Scharstein et al., “High-Resolution Stereo Datasets with Subpixel-Accurate Ground Truth,” GCPR 2014. [Dataset and paper](https://vision.middlebury.edu/stereo/data/scenes2014/) · [Use permission](https://vision.middlebury.edu/stereo/data/) · [Original files](https://vision.middlebury.edu/stereo/submit3/zip/MiddEval3/trainingQ/Motorcycle/).

im0.png, im1.png and calib.txt are original quarter-resolution files. reference.bin stores 741 × 497 unsigned little-endian 16-bit values, top row first. We flipped the PFM vertically, quantized finite disparities to round(d × 256), and encoded mask0nocc pixels of 128 as 65534 (occluded), 0 or unknown disparities as 65535. The maximum disparity quantization error is 1/512 px. Right-view input selects a horizontal coordinate on the reference row. The calibration records up to 0.379 px residual vertical disparity. Dataset terms apply to these assets separately from the code license.
