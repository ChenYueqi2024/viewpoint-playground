# 视角游乐场 · Viewpoint Playground

拖动相机与目标，观察水平像素视差如何决定深度。一个可直接在浏览器里玩的视觉几何实验，由 Yueqi 开发。

[在线体验](https://chenyueqi2024.github.io/viewpoint-playground/)

## v0.1 功能

- 相机与目标拖动、等价键盘滑块，左右图像水平投影。
- 可复现的独立高斯测量噪声，单次估计与误差。
- 30 个间距 × 256 次测量的对照曲线，报告有效估计中位数及失败次数。
- 固定条件的深度估计挑战；导出参数、随机种子和全部汇总结果 JSON。

## 运行与验证

无第三方依赖。用 `python -m http.server 8000` 启动后打开 http://localhost:8000。
数学测试：`node --test tests/geometry.test.mjs`（Node 18+）。

平行、相同内参的针孔相机，位置为 `(-B/2,0)` 和 `(B/2,0)`，朝 +Z；仅模拟 X–Z 平面。虚拟传感器宽 640 px、主点 320 px，世界长度单位 m。深度由 `Z=fB/(uL-uR)` 恢复。场景图为俯视示意，屏幕横纵比例不代表物理比例。

测量在视野之外、非正视差等情况不会伪装成零误差。曲线仅统计有效估计，导出记录包含每个间距的有效与失败次数，避免仅看中位数忽略失效样本。

本项目是教学与工程实践，不是新算法，也不代表真实照片重建效果。未模拟遮挡、错误匹配、镜头畸变或标定误差。后续可扩展垂直坐标、非平行相机与重投影实验。
