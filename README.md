# 视角游乐场 · Viewpoint Playground

拖动相机与目标，观察水平像素视差如何决定深度。一个可直接在浏览器里玩的视觉几何实验，由 Yueqi 开发。

[在线体验](https://chenyueqi2024.github.io/viewpoint-playground/)

## v0.2 功能

- 相机与星星拖动、等价键盘滑块；两种颜色的相机视野、左右模拟画面与视差叠加尺。
- 近景 / 远景 / 手抖三个预设；参照物固定，便于比较水平投影变化。
- 48 次测量的估计点群，区分图内、图外与不可估计；可手动连拍 8 次并暂停，切换参数或离开页面停止。
- 可复现的独立高斯测量噪声，单次估计与误差。
- 30 个间距 × 256 次测量的对照曲线，报告有效估计中位数及失败次数。
- 三个固定条件的挑战：远近与视差、相机间距与噪声、焦距与视野。各关只开放需要的控制，完成后显示解释与会话内徽章。
- 导出参数、随机种子、汇总结果、48 次显示样本与挑战状态 JSON（schema_version: 2）。

建议从“星星在眼前”切换到“星星跑远了”：4 m 到 12 m，其他条件不变，视差变为原来的三分之一。再打开手抖场景，观察估计点群与连拍。

## 运行与验证

无第三方依赖。用 `python -m http.server 8000` 启动后打开 http://localhost:8000。
数学与关卡测试：`npm test`（Node 18+）。

九项自动测试覆盖投影与三角化、无效视差、视野边界、固定种子、近远对照、三关可达解及失败率约束。发布前另以浏览器验证 1440 / 768 / 390 / 320 px 的布局、键盘与拖动、关卡切换、连拍停止和 JSON 导出。

平行、相同内参的针孔相机，位置为 `(-B/2,0)` 和 `(B/2,0)`，朝 +Z；仅模拟 X–Z 平面。虚拟传感器宽 640 px、主点 320 px，世界长度单位 m。深度由 `Z=fB/(uL-uR)` 恢复。场景图为俯视示意，屏幕横纵比例不代表物理比例。

测量在视野之外、非正视差等情况不会伪装成零误差。曲线仅统计有效估计，导出记录包含每个间距的有效与失败次数，避免仅看中位数忽略失效样本。

模拟画面中的星星与两个固定参照物只计算水平位置；大小仅作远近提示。参照物位于 (−0.8, 4) 与 (0.8, 12) m，不参与三角化或遮挡计算。48 次估计点群不是置信区间；统计曲线使用 256 次测量。挑战固定种子，连拍会改变种子；徽章不保存到磁盘，重置实验保留本次会话的徽章，刷新页面清空。

本项目是教学与工程实践，不是新算法，也不代表真实照片重建效果。未模拟遮挡、错误匹配、镜头畸变或标定误差。后续可扩展垂直坐标、非平行相机与重投影实验。
