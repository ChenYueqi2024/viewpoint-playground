想看公式和实验假设？

两台相机位于 X = −B/2 和 +B/2，朝向 +Z，使用相同内参。图像宽 640 px，主点 cx = 320 px，只模拟水平坐标。所有世界长度以米计。

u左 = cx + f(X + B/2) / Z
u右 = cx + f(X − B/2) / Z
d = u左 − u右
Z估计 = fB / d
X估计 = ((u左 + u右)/2 − cx) × Z估计 / f

仅在目标及测量均位于两幅图像内、视差为正时给出估计。没有模拟畸变、遮挡、错误匹配或相机标定误差；这里的趋势不能直接作为真实重建系统的性能结论。
