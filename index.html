A LITTLE MORE OF THE WHY

玩出问题，就展开看看。

按标题展开讲解，Enter / 空格也可以操作。数值会跟随实验更新；打开讲解不会改变参数。

视差，为什么能换成深度？

两台相机从不同位置看同一颗星，星星会落在不同的水平像素坐标上。左右坐标的差，就是视差 d。

在本页的平行双目模型中，相似三角形给出 d = fB / Z，所以 Z = fB / d。相机间距 B、焦距 f 不变时，越远的星星，视差越小。

启用 JavaScript 后显示当前实验数值。

动手验证：先切换“星星在眼前”和“星星跑远了”。深度从 4 m 变为 12 m，理想视差从 140 px 变为约 46.67 px。

出处：OpenCV · Depth Map from Stereo Images。该公式需要已标定、已校正、对应点正确等条件；不能直接套在任意两张照片上。

看得见，为什么还是估不准？

像素位置只偏一点，算出的深度就可能偏很多。对 Z = fB / d 作一阶近似，有 |δZ| ≈ Z² / (fB) × |δd|。目标更远时，同样的像素扰动更容易放大成深度误差。

本页左右测量加入独立、标准差为 σ 的噪声，所以视差噪声的标准差为 √2σ。下面的深度标准差是由本页模型推导的一阶近似，并非论文中的性能结果。

启用 JavaScript 后显示当前近似。

该近似假设噪声足够小、目标可见且匹配正确。视差接近零、出画或出现大扰动时不可靠，不能当作实际误差保证。

点群怎么读：48 个淡点展示多次估计，白色菱形是当前一次。点群不是置信区间，下方 256 次统计才用于关卡判断；无效测量单独计数，不会被当成零误差。

推导基础：OpenCV 的双目深度关系式；这里的误差传播与独立噪声计算为教学推导。

焦距越大，就一定越好吗？

同一宽度的传感器上，焦距变大会放大像素位移，同时缩窄视野。星星一旦离开某台相机的画面，就没有两个可用观测来估计深度了。

本页的水平视场角由针孔模型得到：FOV = 2 arctan(W / (2f))，其中传感器宽 W = 640 px，焦距 f 也以像素计。

这里是理想针孔几何推导；真实镜头还可能有畸变、裁剪与不同的有效传感器尺寸。

01 / 几何起点

一张照片，藏着多少种世界？

一张未知场景照片，通常不足以唯一确定物体的距离与相机位姿。单目视频也能利用移动形成多视角，但若没有已知尺寸或其他尺度信息，纯视觉重建仍有尺度歧义。这里的实验已知相机间距，所以能以米计算深度。

展开：位姿与深度，分别在问什么？

位姿问相机在什么位置、朝哪个方向（平移与旋转）；深度问沿视线走多远才碰到表面。若已知物体上的 3D 点、它们在图中的 2D 对应与相机内参，PnP 可从一张图估计位姿。这与“从任意单张图凭空恢复整个世界”条件不同。

回去试试：同时把相机间距 B 与深度 Z 放大，视差为什么可能不变？

02 / SfM + MVS · COLMAP 2016

先把照片之间的关系拼起来。

SfM（运动恢复结构）从多张照片的对应关系恢复相机位姿与稀疏结构，再由 MVS（多视图立体）补出更稠密的几何。COLMAP 是这条路线常用的开源工具；“找对应点”和“优化几何”都很关键。

展开：为什么有时拍了很多张也拼不起来？

多张照片需要有足够重叠和视角变化。白墙缺少纹理，重复窗格容易匹配错，动态物体会破坏静态场景假设。照片数量并不能代替有效约束。

探索任务：打开 COLMAP 教程，找找 feature matching 与 bundle adjustment 分别解决什么问题。

Schönberger & Frahm, Structure-from-Motion Revisited, CVPR 2016.

03 / 外观与渲染 · 2020 / 2023

知道形状以后，还想看见光。

NeRF用神经场表达颜色与体密度，通过体渲染合成新视角；原始方法用已知位姿的照片优化场景。3D Gaussian Splatting改用可优化的三维高斯及快速投影渲染，推进实时新视角展示。

展开：画面漂亮，等于几何准确吗？

新视角合成关心从别处看起来如何。模型可以很好地拟合观测图像，却在未见区域或几何上产生误差。评估时要分清图像质量、几何精度与渲染速度；NeRF / 3DGS 也不自动等于文本生成模型。

04 / 学习几何 · DUSt3R 2024 → VGGT 2025

能不能，让网络一眼看出结构？

DUSt3R把成对图像重建写成点图回归，多图可再做全局对齐。VGGT用前馈网络从一张到多张图像预测相机、深度、点图和点轨迹，将多种几何任务放到一起。

展开：point map 和“前馈”是什么？

点图为图像像素关联三维坐标；前馈指推理时用网络直接预测。训练阶段学到了先验，因而可以给信息不足的输入提出估计；这并不消除单张图的几何歧义，也不保证陌生场景都准确。网络预测与后续几何优化仍可结合。

探索任务：打开 VGGT 的交互结果，想想输入照片更少、重叠更低时，应怎样检验输出可靠性？

Wang et al., DUSt3R, CVPR 2024；Wang et al., VGGT, CVPR 2025.

05 / 并行发展的生成路线 · 2022 / 2023

没见过的背面，交给想象？

DreamFusion借助预训练 2D 扩散模型，以 SDS 信号优化三维表示，实现文本到 3D。MVDream学习多视图扩散先验，让生成视角之间更一致，并用于三维生成。

展开：为什么“每个角度都好看”仍然不够？

如果每张图各自生成，同一个物体可能在不同角度长出互相矛盾的细节。多视角一致性要求这些图能共同解释为一个场景。生成先验能补充未见区域，但补全仍有多种可能。

探索任务：在 DreamFusion 展示中挑一个物体，从背面再看一次；想想“像真的”与“真是这样”需要什么不同证据。

Poole et al., DreamFusion, 2022 预印本；Shi et al., MVDream, 2023 预印本.

06 / 加入时间与行动 · Genie 2, 2024

如果往前走一步，世界会怎样？

当场景开始随时间与操作变化，问题不再只是换个相机角度。World model研究对环境及其演化的建模；不同工作可能预测潜在状态、视频或其他量。Genie 2 是动作可控、生成交互环境的一例。

展开：能走进去，就算理解物理世界了吗？

生成交互画面不保证内部存在可导出的、尺寸准确的 3D 地图，也不自动保证长期记忆、几何一致或物理正确。研究还要追问：走回来物体还在吗？动作真的导致预期变化吗？长时间互动会漂移吗？

想看公式和实验假设？

两台相机位于 X = −B/2 和 +B/2，朝向 +Z，使用相同内参。图像宽 640 px，主点 cx = 320 px，只模拟水平坐标。所有世界长度以米计。俯视图横纵坐标采用不同显示比例，不能从屏幕直接读出物理角度。

u左 = cx + f(X + B/2) / Z
u右 = cx + f(X − B/2) / Z
d = u左 − u右
Z估计 = fB / d
X估计 = ((u左 + u右)/2 − cx) × Z估计 / f

浅青色、浅粉色区域分别表示相机的水平视野。淡色点为同一组参数下 48 次独立测量的有效估计，不是置信区间；下方统计使用 256 次测量。模拟画面中的物体大小只作远近提示，估计仅使用星星的水平坐标。参照物固定在 (−0.8, 4) 和 (0.8, 12) m，不参与估计。

仅在目标及测量均位于两幅图像内、视差为正时给出估计。没有模拟畸变、遮挡、错误匹配或相机标定误差；这里的趋势不能直接作为真实重建系统的性能结论。挑战使用固定种子；连拍改变种子，切换参数或离开页面会停止连拍。
